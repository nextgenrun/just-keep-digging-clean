# Demo

Demo-profile progression and ending systems. These systems configure the
production gameplay loop; they do not fork mining, saves, movement, or world
authority.

`UnderstarEndingSystem.js` owns the demo-only 2,000 m discovery state, deferred
art request, enormous world-space Understar presentation, interaction prompt,
versioned persistence, and injected ending-overlay boundary. Full-review keeps
the ending inactive so Level Two review remains unchanged.

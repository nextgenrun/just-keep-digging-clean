# Tiled world retirement manifest

Status: staged, not physically moved yet.

The default visible renderer was disconnected from the Tiled-era visual assembly on 2026-07-16. The former assembly remains available only through `?worldVisualRuntime=legacy` while gameplay landmarks and the hidden layout are migrated to a semantic blueprint.

Files scheduled for this archive after the final rollback removal include the generated Tiled override, Tiled background object data, `WorldRenderer`, background master/depth continuation, facade bridge systems, their coordinate-bound motion configs, and their dated exporters.

Repository policy forbids moving still-imported rollback code into `/archive`. This manifest records the exact retirement boundary without breaking the approved rollback.

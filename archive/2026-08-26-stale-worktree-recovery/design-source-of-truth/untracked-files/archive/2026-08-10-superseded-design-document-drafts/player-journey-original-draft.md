# Archived original player-journey draft

> Archived on 2026-08-10. Spelling and contradictions are intentionally retained
> as design provenance. This file is not current implementation guidance.

The first 5 minutes of the game are the most important.

First 5 minutes >>> first 2 hours >>> all other gameplay.

This is because of the 2 hour refund window we want too polish the first 2 hours
of active gameplay the most too prevent refunds, and hook the player so they
keep playing and we have a high return rate.

## First 5 minutes

Toturial is always optional. If player decides no toturial - ad with text are u
sure u want too skip the toturial and figure out the game and its controlls by
yourself? "type yess" popup where player has to type yes.

Than player can chose gamemodes.

Casual: relax dig more dig deeper gameplay experience no player loss no time
pressure.

Hardcore: intended game experience where player constantly has to analyse risk
reward and digging deeper brings bigger risk. Death is semi permanent permanent,
player has 2 lifes; on first death in normal hardcore always offer one free
revive. We want to revolve the game around this experience as the primairy
experience but offer casual for a player that does not like permadeath.

A third hidden gamemode shall be added called one-life-hardcore wich actually
has only one life.

## Toturial

Player spawns inside town and is unable to leave town. 3 2 dirt blocks and one
copper blocks spawn in town wich player has to dig (current version as of
10-08 only one block spawns).

After player lears how to dig blocks we introduce the merchants where player
can buy upgrades. Town should be close off with unbreakable bedrock untill
player finishes. Player has to have pressed flight shift and learned flight
exist before exiting the toturial and allowed to dig into the ground.

New adition: add a "ghost toturial player" doing the moves that player is
supposte to do so he knows where to go.

Add a second popup once player starts digging into ground again saying press
shift too fly; fade out after 10 seconds.

If player goes outside of town but doenst drop down using S key, after 20
seconds add the ghost player backin. He drops down, add UI popup saying press S,
he digs blocks and shows the player what he is supposte to do.

Player will always find his first teleport tile on 15 meters dept to introduce
the teleport mechanic too player. This is always the same no mather game mode,
weather or player choose to skip or do the toturial.

## How will the player understand the controls?

We should look into streamlining/creating multiple logical natural feeling
inputs for basic actions. Multiple keys can have the same action tied too them.

For example F = dig, Space should olso be dig.

WASD is walking/movement; arrow keys should olso be walking and movement.

We will olso support the player by adding controls inside the UI similair too
the current I inventory UI saying I and being clickable.

We should add a small subtle element in UI saying ESC and make it clickable.
This opens the escape menu and allows player too see the Controls tab if they
experience issues with the controls.

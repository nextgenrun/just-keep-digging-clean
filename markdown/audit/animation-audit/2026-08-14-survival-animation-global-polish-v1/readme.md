# Survival animation global polish v1

This package is the evidence database for the 2026-08-14 production-wide
animation, transition, drift, skating, and display-size audit.

Runtime sources remain authoritative. Files in this directory document the
measured before/after state and are not loaded by the game.

The audit preserves approved animation keys, frame order, frame rates, contact
timing, movement authority, and collision geometry. Any runtime correction must
be reversible and separately covered by a production contract.

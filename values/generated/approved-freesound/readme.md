# Approved Freesound runtime data

Generated, immutable, family-split projections of the user's exact 562 approved
IDs and their measured local derivatives. Rebuild only through the explicit
`pipelines/audio/prepareFreesoundApprovals.py` command and frozen export.
Do not hand-edit these generated JavaScript files. Preparation tuning is owned
by `values/freesoundAudioPreparation.json`; gameplay tuning by
`values/freesoundAudio.js`. No rejected or unreviewed entry belongs here.

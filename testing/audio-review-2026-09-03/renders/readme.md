# Reproducible audio audit renders

Generated by `pipelines/audio/auditReviewedAudioMix.py` from approved sources
and `../mix-settings.json`. WAV files are ignored by Git and are local evidence,
not runtime assets. Results, source placements and headroom are recorded in
`../rendered-volume-audit.json`. These renders exclude existing music, speech,
and procedural effects and do not establish calibrated speaker loudness.

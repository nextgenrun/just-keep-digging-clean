# v11 Skyline Motion Mockup v1

Preview-only motion study for the surface skyline contained in:

`exports/dig-game-world-edit-v-11-08-07-2026-;1-img-test.tmx`

The mockup uses the exact v11 band-01 master image and adds non-destructive browser overlays for multi-depth cloud drift, twinkling stars, chimney smoke, warm window pulses, moon haze, rotating windmills, shooting stars, and sky parallax. The stronger v2 motion defaults to 1.6x intensity so movement remains readable at conversation scale. Nothing here is loaded by game time.

Run the project server and open:

`http://127.0.0.1:8080/testing/animation-sandbox/v11-skyline-motion-mockup-v1/index.html`

# Real surface living background V1

Review-only Seedance motion study built from the current runtime surface owners,
not from a newly generated mockup. `real-surface-world-reference-v1.png` combines
the production town beauty crop, exact slate surface cap, and active Level One
ground facade without rescaling or regenerating their pixels.

The single boundary at source Y 534 is the outdoor walk surface. Everything
below it is one continuous earth cross-section; there is no underground floor,
shelf, room, or second boundary.

The video pass uses this reference as a first frame only. It asks for a visibly
traveling wind cycle across the tree canopy, surface grass, smoke, and clouds.
Final review loops are built as deterministic forward/reverse cycles so a model
endpoint cannot create a harsh reset.

`index.html` compares four final eight-second palindrome loops. It opens on
candidate 04 because that clip combines the strongest measured upper-world
motion with the best upper-world-to-earth movement ratio. The raw generated
half-cycles remain under `raw-v1/`; final loops and motion/seam measurements are
under `loops-v1/`.

See `qa-report.md` for the measured motion, encoded seam, and browser playback
checks. These remain review candidates: the model still introduces some global
light/earth drift, so none of the videos are wired into the production renderer.

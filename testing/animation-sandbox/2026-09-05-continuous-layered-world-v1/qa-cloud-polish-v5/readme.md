# Level 1 cloud composition and fade polish V5

Actual canonical serve.py demo frames for the removal of ground cloud/mist,
compact cloud ceilings and landscape-edge corrections. The isolated browser
is a fallback because the in-app automation kernel cannot execute JavaScript.
The existing review route keeps saves disabled. Before and after captures,
render-state checks and the final gallery are stored here.

Open gallery.html for the 24 paired canonical views and 24-second MP4.
after-verification.json records 26 final route/altitude/weather views, including
two wide-view diagnostics. runtime-joins.json checks actual texture coverage
and neighbour guards; motion-verification.json records the real moving scene.
contract.json, geometry-checks.json and visual-contract.json hold focused
regressions. Wide zoom exposes a separate existing screen-overlay boundary;
normal review zoom is 1. The Town video hash remains protected.

# Survivor Side Combo Review v1

Review-only chooser for four unarmed sideways-combo candidates. It draws the
real Survivor UAL Jab/Cross sheets plus the approved Blender v2 `MINER_attack`
and `MINER_dig_side` sheets at the game’s 0.8-tile scale and 31×75 collider.

The selector is local-browser state only. It deliberately does not import or
mutate `UalMiningComboSelector`, player profiles, save data, or production
combo tuning. Choose a candidate here before any new combo is promoted.

# Current runtime vs Mixamo locomotion comparison v1

Review-only animated comparison of every active Dig Game locomotive family.
The page uses the exact current runtime sheets on the left and V4-retargeted
Mixamo candidates on the right, with synchronized playback, game-scale and
inspection-scale views, anchor guides, local verdicts, and a full ground chain.

It does not preload, register or promote any candidate. The full jump and
falling clips are explicitly future/reference material because the player has
no jump mechanic. Decisions are stored only in browser local storage.

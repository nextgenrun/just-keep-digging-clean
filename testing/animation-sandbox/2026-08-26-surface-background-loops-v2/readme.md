# Surface background loops V2

This review uses the current surface-world owners as one composition while
keeping their runtime roles separate:

- `production-beauty-crop-v2.png` is the exact upper town beauty crop.
- `loops-v3/*.mp4` contains only the animated sky, forest, town, and air.
- `static-ground-context-v2.png` contains the separately composed production
  slate floor and Level One earth shown below the video.

The three final candidates are approximately 18-second, silent H.264 Seedance
Mini cycles. They are camera-locked, play forward only, and use a three-second
tail-to-head overlap followed by a 1.5x temporal stretch. There is no reverse
half, ping-pong playback, animated ground, or second underground floor.

Candidate 02, **Town air**, is the default because it keeps tree motion calm
while adding restrained chimney smoke and local lamplight activity. Candidate
01 is more canopy-led; candidate 03 has the strongest atmosphere.

Open `index.html` through the local HTTP server. The **Test the seam** button
jumps to the last 2.5 seconds so the wrap can be inspected quickly. This is a
review artifact only; no production renderer or gameplay value is wired.

See `qa-report.md` and `loops-v3/loop-manifest.json` for measurements and exact
source/output hashes.

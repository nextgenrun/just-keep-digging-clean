# Final forward-only cyclic loops

These are the three review-page candidates. Each 1470 x 436 H.264 file contains
only the upper background, measures zero global scene translation, and closes a
forward-moving source through a three-second overlap. The closed cycle is then
slowed to approximately 18 seconds. No ground, audio, reverse segment, or
ping-pong playback is present.

`loop-manifest.json` records hashes and drift, motion, per-frame, and seam
measurements. `motion-contact-sheet.png` samples all three loops across time.

# Mixamo combat sequence review v2

Review-only interactive combat library and sequence builder for the approved
Survival V4 character. Twenty-four clean Mixamo carriers cover punches,
alternate boxing mechanics, elbows, knees, low/high kicks and grounded mixed
chains. Every carrier is retargeted at 1024 px, downsampled once, and exposed
as an individual motion plus SIDE, UP and DOWN rhythm recipes.

The page compares proposed chains against the current repeated attack, shows
the 94 px target tile and 31x75 collider, supports game-scale viewing, and saves
Accept/Maybe/Reject verdicts only in the browser. It never imports production
player profiles or changes runtime animation registration, mining contacts,
cooldowns, hitboxes, progression or save data.

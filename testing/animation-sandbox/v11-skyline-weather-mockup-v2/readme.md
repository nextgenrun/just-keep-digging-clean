# V11 layered skyline weather mockup v2

Interactive, mockup-only study for the surface skyline authored in
`exports/dig-game-world-edit-v-11-08-07-2026-;1-img-test.tmx`.

This version separates the flattened art into depth layers so windmill rotors
animate behind their towers. Time and weather controls drive cloud parallax,
wind, precipitation, fog, lightning, celestial visibility, smoke, window
activity, and small ambient life details. Nothing in this folder is wired to
the production Phaser runtime.

Open `index.html` through a local web server. Rebuild the derived visual layers
with `ai-tools/2026-07-11-build-v11-skyline-layer-assets.py`.

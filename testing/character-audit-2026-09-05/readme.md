# Main character audit - 2026-09-05

Review evidence for the current default Survival character. This directory does not alter runtime assets, settings, saves, or animation registration.

audit-current.py inspects current pixels and prepares evidence boards. Silhouette distances flag comparisons for review; they are not perceptual quality scores or gameplay proof.

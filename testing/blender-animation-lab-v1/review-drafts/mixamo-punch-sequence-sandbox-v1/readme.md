# Mixamo combat sequence sandbox v2

Review-only source, retarget and render workspace for broad unarmed Mixamo
combat candidates on the approved Survival V4 character. It contains 24
individual punches, boxing variants, elbows, knees and grounded kicks plus
native multi-hit chains intended for UP, DOWN and side-combo feel testing.

Nothing in this directory is loaded by production. The sandbox cannot modify
player profiles, mining contacts, cooldowns, hitboxes, save data or runtime
animation registration.

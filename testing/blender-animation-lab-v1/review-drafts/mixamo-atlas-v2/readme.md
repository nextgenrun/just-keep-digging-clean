# Mixamo atlas v2

Review-only V4 retarget batch for the expanded 130-candidate Mixamo audit.
This folder contains only the strongest missing locomotive proofs: additional
walk, run, sprint and 90-degree turn candidates rendered on the approved
Survival V4 character.

The wider browser atlas also lists source-only Mixamo prospects. Those remote
previews are labelled as motion scouting and are never treated as material,
brightness or deformation proof. Nothing here is registered or loaded by the
game runtime.

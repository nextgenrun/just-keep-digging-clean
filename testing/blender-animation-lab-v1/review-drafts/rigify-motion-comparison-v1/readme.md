# Original versus Rigify motion comparison v1

Matched walk, attack and run review renders comparing the current original rig
with the generated Rigify candidate. Both sides use the current actions, V4
materials, full glove correction, matched camera, lighting, resolution and
timing. This directory is review-only and is never consumed by runtime.

The V2 diagnostic derivatives add a third synchronized silhouette-displacement
panel. Orange traces the current original, cyan traces the Rigify candidate and
white marks overlap. The interactive comparison adds frame scrubbing, a movable
wipe, A/B flicker and full-body/face/hands-hips/knees-feet zoom presets.

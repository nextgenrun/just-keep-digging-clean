# Rejected Superman pose editor v1

This over-controlled review attempt is superseded by `../superman-horizontal-idle-v1/`. It is not loaded by the game runtime.

1. Open the file in **Object Mode**.
2. Select a coloured ring and press **G** to move a whole arm or leg.
3. Select the orange **BODY TILT** ring and press **R** to make the whole body fly.
4. Switch to **Pose Mode** only for the three visible bones: hips, chest, and head.
5. Use **Save As** to keep a pose variant. Reopen the original file to reset.

The file begins as a frozen upright idle pose. A later approved pose can be baked into flight frames; no gameplay asset or collider changes here.

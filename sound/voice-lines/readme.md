# Voice Lines

Authored and generated speech assets used by `VoiceLineManager`.

- `player-voice-lines/` contains the ambient player catalog.
- `npc-voicelines/` contains merchant catalogs.
- `event-driven-grok-v1/` preserves the rejected one-line pilot.
- `event-driven-grok-v2/` contains the extensive multi-event audition library.
- `player-character-leo-v1/` contains the 96-clip, 16-family runtime LEO library.
- `player-character-leo-v1/` contains the 96-clip, 16-family runtime LEO library.

API credentials never belong in this directory. Generated speech must retain a
manifest with model, voice, text, estimated cost, and content hash.

# Event-driven Grok voice library V2

Review-only audition library for contextual gameplay speech generated with
`x-ai/grok-voice-tts-1.0` through OpenRouter.

- `2026-08-30-event-voice-library-v2-source.json` is the approved generation
  input and anti-spam design catalog.
- `audio/` contains generated MP3 candidates.
- `2026-08-30-event-voice-library-v2-manifest.json` is written incrementally
  with request, cost, generation ID, byte-count, and hash provenance.
- `review/` contains the local interactive audition page.

The V1 earthquake clip is rejected and is not part of this catalog. API keys
must never be written into this directory or any manifest.

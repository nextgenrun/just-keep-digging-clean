# Public SFX candidate index

Review-only public discovery queue for the production audio gaps identified on
2026-09-01. Every linked Freesound page declared Creative Commons Zero when it
was checked. The Kinoton pages also link separate creator terms, so those two
entries carry an additional license-review flag.

No remote file was downloaded, copied, normalized, approved, or wired by this
index. Freesound requires an account for most original downloads. A candidate
must be downloaded from its canonical page, hash-recorded, listened to, and
explicitly approved before it can leave this inbox.

The playable expansion in the adjacent UNDERSTAR review sandbox instead uses
assets that were already present locally: source-approved Sonniss GDC slices,
GOOD-tag weather loops, and accepted creepy candidates. Sonniss source approval
still does not equal runtime approval. The applicable bundle license permits
commercial project synchronization and modification while prohibiting raw SFX
redistribution and AI usage.

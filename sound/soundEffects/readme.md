# Sound effects

Production sound effects loaded and routed through `sound/SoundSystem.js`.

- `costume-sounds/` contains the established mining, footsteps, impacts, and related gameplay cues.
- `ui/` contains compact interface-selection and confirmation cues.
- `approved-sfx-findings-v1/` contains only sounds explicitly rated `good` in the 2026-08-14 SFX review.

Review exports must remain under `sound/library-v2/SoundLibrary_Review/` until a human rating explicitly approves promotion.

# Underground biome source plates V1

Status: source art retained; procedural overlay presentation rejected.

The ten 1536 × 1024 PNG paintings in this folder remain the approved Keyframe A
source plates. The earlier Canvas/Phaser-shape motion experiment was removed
because its drawn lines, particles and circles did not match the quality of the
paintings.

`index.html` now redirects to the actual moving-image review:

`../underground-biome-baked-motion-v2/index.html`

That V2 gallery plays the same VP9 WebM files used by Phaser. Motion is encoded
inside the finished image, including the subtle whole-image float. There is no
Canvas renderer or procedural visual effect layered over the art.

`2026-07-26-imagegen-prompt-manifest.md` preserves the original ten-art
direction. The painted keyframe-B edits are in
`../underground-biome-baked-motion-v2/`.

`WorldModel` remains authoritative for ground and collision. Buildings, bridges,
roots, machinery and other scenic silhouettes in these images are background
elements only.

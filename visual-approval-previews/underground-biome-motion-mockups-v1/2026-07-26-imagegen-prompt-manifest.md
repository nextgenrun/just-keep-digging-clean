# Underground Biome Motion Mockups V1 — ImageGen Prompt Manifest

Generated with the built-in ImageGen workflow on 2026-07-26.

Shared prompt contract:

- New 1536x1024 cinematic painterly 2D side-view underground environment.
- The supplied production WebP is a palette, material, depth, and darkness
  reference only; every output must be a fresh composition.
- Background scenery only. No foreground playable ground, collision silhouette,
  close ledge, player, creature, HUD, UI, text, logo, watermark, or border.
- Buildings, bridges, roots, machinery, rings, and other structures remain far
  behind the gameplay plane.
- Preserve a dark central play corridor, controlled highlights, and hard-darkness
  compatibility.
- Compose specific visual cues that can be reinforced by a restrained runtime
  loop instead of trying to bake movement into the still image.

# Level One Biome Depth Diversity V1

This review pack owns the 156 built-in ImageGen sources added to deepen the
existing fifty-family Level One visual field across 0-2000 m: fifty tertiary
ground plates, thirty four-piece identity-kit atlases, fifty scenic
alternatives, fourteen transition alternatives, and twelve rare major
landmarks.

Fifteen of the scenic alternatives are deliberate hard-swap experiments: three
per parent material. They make a blunt palette, silhouette, and fantasy-language
change while retaining the parent geology at grounded edges. These experiments
occupy existing background-role slots rather than adding another layer.

Runtime routing replaces choices inside the existing terrain, generated-role,
and transition placements. It does not add placement density, terrain
authority, collision, resources, drops, map topology, or save data. The exact
prompts, untouched sources, optimized runtime derivatives, hashes, manifests,
and contact sheets live in this pack.

Rollback: `?levelOneSourceFamilies=0` removes the family-specific ground and
role variants; `?levelOneBiomeField=0` restores the previous Level One material
field and transition routing.

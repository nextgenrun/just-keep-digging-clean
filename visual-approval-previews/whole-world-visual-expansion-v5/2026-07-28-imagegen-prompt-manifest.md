# Whole-World Visual Expansion V5 - ImageGen Prompt Manifest

Generation mode: built-in ImageGen, one distinct call per 1536x1024 source.

## Shared visual contract

- Premium hand-painted 2D raster art; no HTML, canvas, procedural, or cheap overlay art.
- Background buildings, bridges, roots, ruins, rails, and machines remain distant scenery.
- Terrain paintings fill only the authoritative solid destructible-ground mask.
- Surface sources use a flat green isolation field solely to recover their painted alpha edge.
- Strong asymmetric macro events replace centered circles, safe wallpaper, and repeated folds.
- Outer card edges remain compositionally quiet for overlap blending.
- No players, creatures, UI, text, logos, tile grids, or gameplay collision silhouettes.

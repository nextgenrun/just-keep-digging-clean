# Level One Biome Generated Roles V2

Review package for the sixty new built-in ImageGen outputs that expand every
Level One biome family with a background relief, ground/sidewall formation,
and foreground prop. The existing twenty hero signatures are retained, making
an eighty-asset generated runtime library across twenty source families.

The contact sheet presents one family per row and the four runtime roles in
columns. Sources are untouched lossless RGBA PNGs; runtime derivatives add only
an outer alpha falloff and WebP encoding.

These assets are visual-only. They do not define collision, terrain, resources,
gameplay rules, or save data.

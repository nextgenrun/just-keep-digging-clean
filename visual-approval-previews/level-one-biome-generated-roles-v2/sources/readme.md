# Level One Biome Generated Role Sources V2

Untouched `1536x1024` RGBA PNG outputs from built-in ImageGen. Each of the
sixty files came from its own generation call: three new visual roles for each
of the twenty Level One biome families.

These lossless files are provenance and rebuild inputs. Runtime uses the
alpha-gated WebP derivatives in `level1-biome-generated-roles-v2/`.

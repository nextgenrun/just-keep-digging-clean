# Aligned Ground Damage V5 Review

`01-aligned-v5-foreground-registration.png` is a browser-captured WebGL review
board for the production `WorldVisualDamageImagePainter`.

It shows all twelve real raster states at the exact 94 px gameplay size over
unchanged production foreground frames from weathered roots/dirt, blue
caverns/stone, core magma/lava dirt, and blackglass/obsidian. Each row keeps the
same foreground frame, motif, transform, center, and scale across the twelve
states so progression and registration can be compared directly.

The review harness is
`testing/2026-08-26-aligned-ground-damage-v5-harness.html`.

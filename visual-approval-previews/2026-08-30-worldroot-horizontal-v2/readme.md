# Worldroot horizontal direction v2

Approved direction: one huge, asymmetrical living root-road with substantially
more horizontal space, irregular biome countries, walkable branch terraces,
and an enormous blue Crown Star visible from the beginning at the upper-right.

The production pair is preserved in
`sprites/environment/worldroot-v1/`. The living and consumed states use the
same silhouette; consuming Stars scars the relevant region without turning the
tree into a separate progression authority.

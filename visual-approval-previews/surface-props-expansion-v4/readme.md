# Surface Props Expansion V4

**Date:** 2026-07-29  
**Status:** review only  
**Requested inventory:** 100 individually generated prop candidates  
**Runtime changed:** No

This library extends the approved surface visual language without replacing or
rewiring the existing prop sets. It is divided into five complementary
families:

- Village Life and Civic Detail
- Minehead Industry and Transport
- Forest Homestead and Garden
- Celestial Workshop and Survey
- Expedition and Weather Readiness

Every candidate is generated separately at high resolution using the approved
V2 physical-scale sheet and V3 200-object overview as style references only.
Sources use a flat removable chroma background, one planted side-on subject,
generous padding, and no terrain, landscape, sky, moon, celestial body,
character, UI, text, or baked atmosphere.

Nothing in this directory is imported, registered, preloaded, assigned an
asset key, placed in the world, or consumed by Phaser. Approval and selection
must happen before any production processing or wiring.

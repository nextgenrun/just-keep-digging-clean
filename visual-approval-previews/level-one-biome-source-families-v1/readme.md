# Level One Biome Source Families V1

Twenty independently generated `1536x1024` RGBA signature formations provide
one unmistakable foreground identity for each Level One visual biome profile.

- `sources/` retains the untouched built-in ImageGen PNGs.
- `2026-08-29-level-one-biome-signature-prompts-v1.md` records the shared
  production constraints and all twenty family directions.
- `2026-08-29-level-one-biome-source-families-v1.json` records hashes, alpha
  coverage, dimensions, runtime paths, and the exact 5-to-20 family expansion.
- `2026-08-29-level-one-biome-signatures-contact-v1.jpg` is review evidence.

`reviewOnly: false`; `productionChanged: true`. Phaser loads only the derived
WebPs under `sprites/backgrounds/world-visual-v2/depth/level1-biome-signatures-v1/`.
The formations are seed-anchored, terrain-masked, non-colliding, visual-only,
and removable with `?levelOneSourceFamilies=0`.

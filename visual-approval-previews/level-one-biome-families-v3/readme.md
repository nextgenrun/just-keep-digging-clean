# Level One Biome Families V3 Review

This folder contains the source specifications, exact built-in ImageGen prompt
manifest, untouched transparent PNG sources, validation manifest, and contact
sheets for the 30-family expansion that raises Level One from 20 to 50 visual
families. Runtime-ready WebPs live in the corresponding V3 depth asset folder.

The V3 `ground` column is a transparent terrain-edge landmark. Continuous
family ground fill is reviewed separately in
`../level-one-biome-ground-materials-v1/`.

# Ground Damage Piskel Production Proof

This folder contains browser-rendered evidence from the production preload
resolver and `WorldVisualDamageImagePainter`.

- `01-production-polished.png`: default polished Piskel V2 atlas.
- `02-production-legacy-atlas-rollback.png`: the same production painter with
  `?groundDamageAtlas=legacy`.

Both captures use the 94 px logical tile size and render every material across
all 12 damage states. They are regenerated by
`testing/2026-07-30-ground-damage-piskel-production-live-visual.mjs`.

# Level One biome ground materials V1

This review pack owns the sixty built-in ImageGen source plates and derived
runtime assets that close the true-ground gap for the thirty added Level One
families. Every family receives a primary and secondary full-coverage terrain
material. These are not foreground props or isolated formations.

The runtime plates use the existing complementary left/top incoming feather,
solid-tile geometry mask, demand streaming, lighting tint, and organic Level
One biome field. `?levelOneSourceFamilies=0` restores the retained terrain
partitions and prevents these assets from being requested.

The pack contains the exact sixty prompts, untouched sources, source/runtime
hashes, full-edge opacity and RGB-variance measurements, a master sheet, and
five parent-region sheets. Together with the thirty-six retained plates, Level
One now has ninety-six true ground concepts. The companion scenic role library
contains 200 transparent assets; the combined generated family library is 260.

# Earthquake Dodge Layering v1

Browser captures from the test-only Phaser review at
`testing/animation-sandbox/earthquake-dodge-world-v1/`.

- `01-warning-footprint.png`: ceiling fracture and predicted landing footprint
  below the player.
- `02-lateral-dodge.png`: player clears laterally while the authored boulder
  falls above the player layer.
- `03-safe-impact.png`: foreground impact fragments land in the warned zone
  after the player has cleared it.

These are visual proposals, not production captures. The mockup does not change
live earthquake timing, spawn rules, damage, collision, or terrain mutation.

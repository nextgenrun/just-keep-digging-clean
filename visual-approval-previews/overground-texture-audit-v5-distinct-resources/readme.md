# Distinct embedded resource references V5

The two three-ground boards are the approved visual reference for all ten
resource identities:

- `01-common-resources-three-grounds.jpg`: Stone, Copper, Bronze, Iron, Steel.
- `02-deep-resources-three-grounds.jpg`: Silver, Gold, Obsidian, Ember Ore,
  Magma Crystal.

These labeled boards are never loaded by the game. Production uses isolated
transparent derivatives that preserve the same natural, ground-embedded
language across multiple authored silhouettes.

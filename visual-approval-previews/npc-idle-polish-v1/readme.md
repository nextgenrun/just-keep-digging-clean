# NPC Idle Polish v1

Preview-only merchant idle animations created on 2026-07-11. Nothing in this folder is loaded by the game.

- `money-monster`: polished from the supplied transparent WebM.
- `bobo-merchant`: polished from the supplied Dog Adventurer transparent WebM.

- `*-alpha.webm`: full-resolution transparent review master.
- `*-preview.webp`: smaller checkerboard-backed animated review image for quick visual approval.
- `index.html`: side-by-side animated browser review page.

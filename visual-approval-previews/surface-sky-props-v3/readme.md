# Surface and Sky Props V3 Review

Review contact sheets for all 200 available prop frames. Category boards
include physical-height and source classification labels; the overview is a
compact palette proof, not a requirement to place every asset. These boards
are not loaded by Phaser.

The production assets live under
`sprites/environment/surface-sky-props-v3/`. The review must demonstrate
distinct silhouettes, transparent edges, believable physical size, chapter
palette continuity, and clear Titan/portal/interaction exclusions.

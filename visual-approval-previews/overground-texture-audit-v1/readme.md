# Overworld texture audit v1 — REJECTED

This selection is rejected. It used transparent resource/reward decals and an
obsolete Teleport Up texture. Nothing in this folder is an approved production
reference. The corrected opaque ImageGen selection is documented in
`../overground-texture-audit-v2-imagegen/`.

These sheets compare every player-visible resource recognition texture and
special-tile marker at native gameplay scale.

- `01-special-tiles-current-vs-earlier.png` compares the former default scenic
  art with the clearer earlier emblem set and oldest source tiles.
- `02-resources-current-vs-earlier.png` compares former physical ore clusters,
  earlier transparent vein markers, and legacy full-tile damage art.
- `03-other-special-markers.png` records the keep decisions for geode, chest,
  relic, and glow-crystal markers.
- `04-selected-production-textures.png` is the final native-94 px QA sheet for
  the promoted combination.

# Surface Prop Worldbuilding Mockups V1 — Prompt Manifest

**Workflow:** built-in image generation  
**Reference role:** recent live UNDERSTAR screenshots supplied style, gameplay
camera scale, materials, sky, ground, and portal-island language.

## Shared prompt direction

Create premium painterly 2D side-view UNDERSTAR game-environment mockups with
dark gothic medieval-cosmic realism, orthographic gameplay readability,
player-calibrated materials, functional prop clusters, and deliberate open
walking space. Use rear/middle/front scale and atmospheric fade. Keep every
object planted on the terrain contact line. Exclude HUD, text, watermarks,
floating objects, evenly spaced prop rows, showroom layouts, pulse, motion
streaks, and unnecessary characters.

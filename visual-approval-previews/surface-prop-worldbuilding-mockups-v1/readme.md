# Surface Prop Worldbuilding Mockups V1

**Date:** 2026-07-29
**Status:** review only
**Runtime changed:** No

Six composition boards translate the 200-piece surface and sky prop palette
into complete world-building direction. They are not loaded by Phaser.

- Boards 1-3 and 6 cover the seven Level 2 story chapters.
- Board 4 keeps the Level 1 Titan Walk entirely free of V3 props.
- Board 5 confines sky-island dressing to two low outer bookends.
- Production should reconstruct the direction from discrete existing assets,
  preserve authored open walking ranges, and keep every prop transform-static.

The boards use authored size variants `86% / 100% / 118%`, perspective scale
`88% / 100% / 108%`, surface opacity `74% / 92% / 100%`, and sky opacity
`78% / 93% / 100%` as their implementation target.

These images were created with the built-in image-generation workflow using
recent live UNDERSTAR screenshots as visual references.

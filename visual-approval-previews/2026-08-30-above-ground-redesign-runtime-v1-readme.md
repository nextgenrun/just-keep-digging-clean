# Above-ground redesign runtime mockup V1

The Observatory current/redesign pair and the Far East and Starwell redesign captures named
`2026-08-30-above-ground-*-v1.png` come from the review-only Phaser harness at
`testing/2026-08-30-above-ground-redesign-runtime-mockup.html`.

The redesign adds no generated art. It composes the checked-in V4 hero landmarks and V3
surface-prop atlases over existing runtime captures at the same 40 px-per-metre scale used
by the surface visual system. The mockup does not alter gameplay, collision, world placement,
or production rendering authority.

Use Left/Right to move through Town, Arrival Forge, Starwell, Observatory, Frontier, and
Far East. Use Space or R to switch between the untouched current capture and the proposed
existing-assets redesign layer.

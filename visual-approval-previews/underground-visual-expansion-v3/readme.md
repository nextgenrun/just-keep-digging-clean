# Underground Visual Expansion V3

ImageGen-authored source package for the additive underground visual expansion.

- `bg-*.png` files are full-frame scenic backdrops. They remain behind the
  authoritative terrain and never provide collision.
- `ground-*.png` files are transparent terrain-structure plates. Runtime
  derivatives are masked to authoritative solid terrain and remain below ore,
  reward, damage, and emissive feedback.
- The completed package covers ten depth biomes with five new scenic
  backgrounds and five new ground-structure overlays per biome: exactly 100
  production assets.
- Existing approved static backgrounds and smooth V3 motion cards are preserved.
- `2026-07-28-backgrounds-contact-sheet-v3.jpg` reviews all fifty new complete
  paintings.
- `2026-07-28-ground-structures-contact-sheet-v3.png` reviews all fifty
  edge-decontaminated alpha plates over a checkerboard.
- `2026-07-28-imagegen-prompt-manifest.md` records the built-in ImageGen prompt
  contracts and exact asset inventory.
- `2026-07-28-underground-visual-expansion-v3.json` pins source/runtime paths,
  dimensions, hashes, byte sizes, chroma samples, and alpha coverage.

Runtime derivatives live under
`sprites/backgrounds/world-visual-v2/depth/biome-expansion-v3/` and
`sprites/backgrounds/world-visual-v2/depth/biome-ground-structures-v3/`.

No HTML, CSS, Phaser Graphics, particle, or procedural stand-in art belongs in
this package.

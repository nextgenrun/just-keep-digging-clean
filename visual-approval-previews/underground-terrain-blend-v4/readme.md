# Underground Terrain Blend V4 Review Package

This package records the built-in ImageGen masters, prompts, derived runtime
plates, edge-cap contact sheets, and seam comparison evidence for the additive
underground terrain-variation pass.

Production intent:

- remove mirrored/kaleidoscopic foreground folds;
- crossfade complete background paintings at card joins;
- add five authored foreground material plates per biome, including two bold
  fault/upheaval/current compositions;
- add twenty image-backed exposed-top dirt/rock variants per biome;
- preserve the fifty approved ground structures as separate alpha-feathered
  V4 derivatives, with the complete V3 package retained;
- preserve every approved backdrop, terrain material, structure, collision
  rule, and authored layout.

Runtime inventory:

- 50 full 1536x1024 terrain masters and feathered runtime plates;
- 200 painted exposed-top frames across ten atlases;
- 50 feathered derivatives of the approved V3 roots, arches, ribs, and seams;
- one 16-state RGBA blend-mask atlas for complete backdrop paintings.

Rollbacks:

- `?undergroundTerrainVariation=0` disables the 250 new terrain visuals;
- `?groundStructureBlend=0` restores the original V3 structure assets;
- `?undergroundGroundStructures=0` disables the structure layer.

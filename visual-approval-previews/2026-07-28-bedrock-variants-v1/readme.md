# Bedrock Texture Variants V1

Five review-only replacement directions for the Level 1 / Level 2 bedrock
divider. None is wired into runtime.

## Authoritative placement

- Locked surface gate: `x119 / y64`
- Safe bridge: `x120..136 / y65`
- Open bridge undercroft: `y66`
- One-tile divider: `x132 / y67..5064`
- No other underground bedrock

## Options

1. `01-megalith-lock.png` — colossal natural blue-black plates.
2. `02-titan-forge-seal.png` — ancient forged ribs locking crushed bedrock.
3. `03-abyss-scale.png` — overlapping indigo volcanic-glass armor.
4. `04-pressure-strata.png` — folded metamorphic strata welded by pressure.
5. `05-worldcore-lattice.png` — blackstone fused by dull star-metal veins.

source. `2026-07-28-five-bedrock-map-placement-board.png` is the rendered review

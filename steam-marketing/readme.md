# Steam Marketing

This directory contains review-only marketing exports for Steam. Assets here
are not loaded by the game and do not change gameplay, saves, or runtime art.

Each dated package documents its source art, intended Steam placement, and any
promotion caveats. Gameplay screenshots must still be captured from the live
game rather than composed from these marketing exports.

`2026-08-26-cinematic-video-pack-v1/` contains the generated cinematic trailer,
two captioned vertical wishlist shorts, source clips, narration, editable
captions, generation-cost provenance, and final media verification. The two
runtime edits are copied to `sprites/cinematics/`, not loaded from this folder.

`2026-08-26-elevenlabs-promo-shorts-v1/` contains three review-only vertical
social cuts assembled from existing approved cinematic sources and live-game
screenshots with new ElevenLabs narration and sound design.

`2026-08-26-gameplay-demo-trailer-v1/` contains a verified 30-second landscape
gameplay-demo trailer and one 15-second vertical Short built from F9 captures,
Frederick Surrey narration, accessible subtitle sidecars, and a disclosed
gameplay-derived key-art end card. Nothing in the package is published or
runtime-wired.

`2026-08-27-reddit-launch-v1/` is a review-only Reddit launch packet. It maps
verified gameplay and promotional assets to three Reddit-native draft posts,
records the Devvit Scheduler route for a moderator-owned community, and keeps
all scheduling and publication blocked pending community-name and copy approval.

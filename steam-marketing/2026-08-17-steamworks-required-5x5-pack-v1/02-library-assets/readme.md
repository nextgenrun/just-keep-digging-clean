# Library uploads

Upload each file to its named Steamworks field:

1. Library Capsule — 600x900.
2. Library Hero — 3840x1240.
3. Library Logo — transparent, 1280 pixels wide (Steam accepts a logo up to 1280 pixels wide and/or 720 pixels tall).
4. Library Header Capsule — 920x430.

There are four official Library asset types. Do not upload the App Icon or Shortcut Icon through this Library uploader.

# Steamworks upload pack

Use the two numbered folders separately in Steamworks. Do not drop the whole folder into one generic upload area.

- `01-screenshots`: five genuine current-build captures, each 1920x1080 RGB PNG.
- `02-library-assets`: the four documented Steam Library images. Upload these only in the Library Assets area.
- `03-community-client-icons`: the App Icon and Shortcut Icon. Upload these only in Community and Client Icons.

The files are numbered in upload order. The title-menu image is the only menu-only screenshot; the other four are captured from the active game or its in-game progression interfaces. Steam does not treat the App Icon as a Library asset.

Sound Forge Arena V2

Four gameplay cues, three prompt architectures, both viable non-music OpenRouter audio models, and four local mastering treatments. The smaller voice lane tests fresh challengers against Grok, Deepgram, and Mistral.

Why V2 exists: the first batch generated zero SFX. All three SFX requests failed, Gemini was asked for an unsupported MP3 response, and the Bobo transcription source path was stale. This page does not pretend those were valid sound-effect tests.
Waiting for V2 generation

1. OpenRouter non-speech capability

Each GPT Audio model gets one speech control and two SFX probes. Full cue generation runs only if a probe succeeds; this separates a broken route from a real non-speech limitation without burning credits blindly.

2. Generated SFX prompt arena

Compare direct Foley, timed layer sheets, and negative-first constraints. Reject anything containing words, mouth sounds, music, weak transients, or a long cinematic tail.

3. Existing-library mastering arena

The same four handpicked source cues are heard untouched, tight, heavy, and crisp. These previews never overwrite the originals and often provide a more useful game result than a generative model.

4. Focused voice challenger lane

One Bobo line across Grok, Aura, Mistral and five new model families. Multiple voices matter more here than repeating four scripts with one poorly matched identity.

5. Decision rule

Promote nothing automatically. First pick a winning SFX identity per cue, then build a coherent family around it. A model that cannot beat the existing handpick plus a light master should not enter the production pipeline.

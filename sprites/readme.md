# Sprites

sprites directory.

`npc/campfire/worldroot-v2/runtime/` contains the active ten-form Campfire
family: exact 1254 x 1254 source-derived RGBA cutouts with versioned texture
keys and a hash/alpha manifest. The painted RGB sources and prior metal family
remain outside normal runtime selection.

`environment/approved-pillars-v1/` contains the exact five-stage RGBA
production sprites approved for the town Milestone Pillar and Sky Island Star
Pillar, plus their stable decoded-pixel fingerprints and rebuild provenance.

`environment/graveborer-wurm-v1/` contains the ImageGen-authored transparent
masters and optimized runtime WebPs for the Hardcore-only Wurm creature,
committed-path warning seam, and threat-state HUD medallion.

`environment/star-block-pulse-v1/` contains the six black-backed,
ImageGen-authored additive pulse sprites whose colours match the production
Star Block rarity atlas.

`environment/star-block-crystal-v2/` contains the active six normalized
ImageGen crystal cores shared exactly by the live Star Block icon family and
the mined Star Block release. Its manifest pins every core, both atlases, the
approved Choice 1 reference, and the exact 94 px block-to-release / 136 px
release proof.

`environment/star-block-destruction-v1/` retains the six original
high-resolution core masters and supplies the six active crystalline fracture
blooms. The release never substitutes procedural art.

`environment/surface-props-v2/` contains seven isolated, physically scaled
ImageGen Level 2 chapter anchors. They are additive to the retained v1 prop
kit and contain no baked landscape, sky, moon, terrain strip, player, or UI.

`environment/heavenblocks-sky-altars-v1/` contains three coherent ImageGen
altar families with dormant, attuning, and awakened RGBA world sprites. The
surface bank is placed beyond the Titan gallery and uses real progression
state instead of procedural gate circles.

`UI/mining-target-v1/` contains the ImageGen-authored transparent four-corner
overlay used for body-adjacent keyboard and mouse mining targets.

`backgrounds/world-visual-v2/semantic-decals-v1/imagegen-ground-veins-2d-v6/`
contains the approved strict-orthographic resource-overlay sources, extracted
alpha sheets, and deterministic manifest. The active 188 px and 94 px atlases
provide six varied ground-embedded formations per resource, preserve the live
ground beneath them, and contain no 2.5D side faces.

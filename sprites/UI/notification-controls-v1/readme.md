# Notification controls v1

Approved raster controls for the shared transient-notification carousel:

- `notification-previous-v1.png`
- `notification-next-v1.png`
- `notification-clear-v1.png`

The controls match the bronze, blackened-steel, ivory, and purple-crystal
language approved in
`ai-tools/2026-07-28-ui-notification-carousel-mockup-v2.png`. They are generated
as a high-resolution horizontal sheet on chroma green, converted to
transparency, cropped, and downsampled to 128 px by
`ai-tools/2026-07-28-build-notification-controls-v1.py`.

Source files:

- `ai-tools/2026-07-28-notification-controls-source-v1.png`
- `ai-tools/2026-07-28-notification-controls-transparent-v1.png`

Generation prompt:

> Use the notification popup controls in the supplied Dig Game mockup as the
> exact visual direction. Create one production-ready 2D fantasy game UI asset
> sheet containing exactly three separate square control buttons in a single
> horizontal row: left chevron, right chevron, and close X. Match the dark
> inset blackened-steel square, refined bronze/brass beveled rim, warm edge
> highlights, crisp ivory/gold symbols, and subtle purple crystal accents.
> Render front-on, evenly sized and spaced, without labels or extra elements,
> on a perfectly flat solid chroma-green background.

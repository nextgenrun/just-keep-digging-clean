# Focused Celestial Talents

Seven original PNG assets produced with the built-in ImageGen tool: one complete
three-tree selector, three branch foundations with engraved names, a full
button/rank-plate atlas, a transparent upgrade-burst atlas, and a zero-cost unlock variant.

Original pixels and alpha are preserved. `prompts.json` retains the exact
prompts and generated sources; `manifest.json` pins dimensions and SHA-256.
Phaser selects original atlas rectangles and fits them proportionally.

Only the chosen tree's twelve nodes are visible and interactive. Descriptions
come from the existing baked Stars and Talents V2 cards. Ranks use four baked
plaques. Only balances and the upgrade price use live numeric text in wells.
Upgrade feedback follows a successful progression transaction and respects
reduced motion and the existing SFX controls.

Values: `values/celestialTalentFocusUi.js`. Runtime review and focused checks:
`testing/2026-09-06-baked-copy/`.

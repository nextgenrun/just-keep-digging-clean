# Starlight Talent Tree V3 Sources

Retained full-resolution built-in ImageGen sources:

- `starlight-ultrawide-foundation-imagegen-source-v3.png`
- `starlight-plaque-sheet-imagegen-source-v3.png`
- `starlight-carousel-sheet-imagegen-source-v3.png`

The foundation was generated as a native ultra-wide empty production UI with
three card alcoves and a large inspection rail. The two component sheets use a
flat `#ff00ff` chroma background and contain no baked text, letters, numbers,
logos, or generic UI glyphs.

The V3 builder copies the hash-pinned V2 runtime inventory, extracts and
alpha-cleans these V3 components with the installed ImageGen chroma helper, and
writes `manifest-v3.json`.

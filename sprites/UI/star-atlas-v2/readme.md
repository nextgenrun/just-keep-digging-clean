# Star Codex foundation V2

`star-codex-foundation-v2.png` is the authored ImageGen foundation for the
I-key Star Codex. It uses the Titan Archive's collection/detail hierarchy while
preserving the established blackened-steel, brass, and celestial art direction.

The PNG is intentionally empty: rarity labels, Star identities, page controls,
lore, stats, and hit zones are placed at runtime. `values/starIdentityLibrary.js`
owns the measured 1738 x 905 source-space anchors. Runtime placement must map
through those anchors so scaling never drifts away from the baked sockets.

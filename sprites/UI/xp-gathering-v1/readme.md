# XP Gathering V1

Dedicated transparent runtime icons for XP collection feedback. These assets
are presentation-only and never replace resource, Star, or progression state.

- `xp-mote-routine.png` is the quiet everyday and grouped-gain glyph.
- `xp-sigil-special.png` identifies XP and Legend Block progress rewards.
- `xp-crest-level.png` marks a completed player level.

Phaser supplies source-matched tint only to small secondary flecks. The main
green-and-gold glyphs remain unchanged so XP reads consistently across every
resource and Star rarity.

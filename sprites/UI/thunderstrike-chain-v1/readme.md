# Thunderstrike Chain HUD v1

Production backing art for the ten-slam Thunderstrike timing rail. Runtime crops
only the authored lightning track; the ornate socket area is no longer shown.

- `thunderstrike-chain-frame-v1.webp` is the transparent runtime asset.
- `2026-07-26-imagegen-thunderstrike-chain-source.png` is the chroma-key source.
- The source was derived from the player-approved Thunderstrike mockup with the
  built-in image-generation workflow.
- Phaser owns the responsive crop and exact target/needle position. No live
  title, milestone, multiplier, badge, prompt, or feedback copy is created.
- Missing backing art disables the rail instead of shipping a procedural
  placeholder.

Final prompt intent: preserve the approved dark obsidian, bronze-beveled and
electric panel while removing all baked text, numerals, checkmarks, target
fills, needles, and gameplay imagery.

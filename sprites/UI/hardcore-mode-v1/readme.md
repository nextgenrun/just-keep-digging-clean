# Hardcore Mode V1

Approved ImageGen-authored Hardcore interface artwork.

- The oath panel and crest support mode selection, typed confirmations, status,
  and the permanent-death recap.
- `hardcore-death-action-master-v1.png` is the transparent high-resolution
  action-plate master.
- `hardcore-death-action-runtime-v1.webp` is the reusable lossless button plate
  for `TRY AGAIN` and `BACK TO MENU`.

Visible controls use these authored assets with dynamic Phaser text. No HTML,
procedural placeholder, or flat rectangle is a production fallback.

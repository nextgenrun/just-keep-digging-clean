# XP Gathering V2

Nine additional transparent XP glyphs broaden the V1 emerald-and-gold identity.
Three optimized 256 px carriers preserve the original routine, special, and
level silhouettes while their untouched 1254 px V1 masters remain rollback.
All twelve runtime glyphs are presentation-only: XP
amounts, level progression, reward selection, and saves remain authoritative in
their existing systems.

- Routine: faceted diamond, compass mote, and split kite.
- Cluster: interlocked twins, orbit crystal, and three-mote constellation.
- Special: runic seal and Legend laurel.
- Level: compact crown starburst.

Every runtime file is a validated 256×256 RGBA PNG with transparent padding and
is selected through `values/xpGathering.js`. The generated source, prompt
provenance, and alpha correction are documented under `source/`; the checked-in
builder emits the twelve runtime files, manifest, and dark-field review board.

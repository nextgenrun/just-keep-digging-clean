# Star Atlas V1

ImageGen-authored foundation for the third `I`-key inventory tab.

`star-atlas-foundation-v1.png` is a 1536 by 800 transparent-edged fantasy UI
plate with:

- six spacious rarity sockets across the top;
- twelve selector sockets on the left;
- one large identity showcase and dossier on the right;
- three separated reward-stat sockets at the bottom.

Phaser places dynamic rarity/identity copy and exact Star atlas frames inside
those authored sockets. It uses invisible zones for interaction and never
draws visible substitute panels or buttons. The fit remains proportional
inside the shared inventory modal.

The asset is always preloaded with the Star identity atlases so the guide works
in both scenic and legacy world render modes. Prompt provenance is in
`source/readme.md`.

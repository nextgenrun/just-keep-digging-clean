# Star Atlas Foundation ImageGen Source

`star-atlas-foundation-source-v1.png` is the immutable built-in ImageGen source
for the live Star Atlas foundation.

## Final generation prompt

Create one ultra-wide premium fantasy-game Star Atlas UI foundation on pure
black for later alpha extraction. Use luminous midnight navy, restrained
silver, cyan, violet, and warm-gold celestial engraving. Paint six clearly
separated rarity navigation sockets across the top, a spacious four-by-three
bank of twelve star selector sockets on the left, one very large star showcase
with a readable lore dossier on the right, and three distinct reward-stat
sockets below it. Keep generous internal breathing room and strong hierarchy.
Leave every socket empty for exact runtime art and text. No words, letters,
numbers, icons, stars, HTML styling, flat web cards, hover states, characters,
terrain, screenshots, or cropped edges. The result must read as high-quality
painted game UI rather than procedural geometry.

The builder removes only the connected exterior black field, preserves the
painted interior, and scales the resulting alpha asset to 1536 by 800.

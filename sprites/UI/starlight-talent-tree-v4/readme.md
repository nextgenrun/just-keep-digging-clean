# Starlight Talent Tree V4

Production ImageGen presentation for the shared ESC Talent page and physical
Star Pillar.

`starlight-mockup-foundation-v4.png` follows the approved mockup's taller
composition: three large constellation alcoves, fixed authored arrow housings,
three upper navigation plaques, and a separate lower dossier. Runtime Phaser
objects supply only live text, constellation/Engine art, interaction hit areas,
locks, selection light, and progress.

The other 28 runtime PNGs are unchanged approved V3 components copied into this
versioned package so rollback remains a one-line asset-path change. V3 is kept
intact.

The V4 foundation was generated with the built-in ImageGen workflow from the
approved screenshot as a composition and material-quality reference. It
contains no baked dynamic labels, icons, weapons, progress, or fake text.

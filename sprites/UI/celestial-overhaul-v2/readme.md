# Celestial Overhaul V2 UI Assets

Production talent-tree art rebuilt around the live 33-node topology.

- `celestial-talent-foundation-v2.png` is a socket-free 1672x941 foundation.
- `talent-node-frame-v2.png` frames the existing authored talent icons.
- `talent-connector-v2.png` is a restrained stretchable runtime connector.
- `talent-tooltip-v2.png` replaces the legacy gem notification strip with a
  symmetrical Star Pillar hover card and a quiet, readable text field.

The foundation follows the Star Pillar's cobalt slate, dark steel, aged brass,
and cyan crystal language. Runtime code remains authoritative for node and
connector placement; the bitmap contains no false sockets or paths.

Rebuild from the repository root:

```powershell
python ai-tools/2026-08-15-build-celestial-talent-tree-v2.py
```

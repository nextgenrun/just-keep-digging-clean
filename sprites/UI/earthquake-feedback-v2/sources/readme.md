# Earthquake Feedback UI v2 sources

Source role: production-derived ImageGen master and transparent processing
intermediate for the Phaser seismic HUD.

ImageGen mode: built-in image generation with the approved UNDERSTAR player HUD
mockup as a style reference.

Final generation prompt role: one text-free, 5.4:1 antique-brass and blackened
slate seismic status plate with a left crystal medallion, empty runtime-text
field, recessed progress channel, restrained cyan/amber accents, and a flat
magenta chroma background.

- `2026-07-26-imagegen-seismic-status-source.png` is the untouched generated
  output copied from the Codex ImageGen result.
- `2026-07-26-seismic-status-transparent-master.png` is the alpha-cleaned master
  produced with the installed ImageGen chroma-removal utility.

Runtime crops are rebuilt by
`ai-tools/2026-07-26-build-earthquake-feedback-ui-v2.py`.

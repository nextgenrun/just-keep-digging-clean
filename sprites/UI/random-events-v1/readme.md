the player-approved Sleeping Jackpot V2 direction on 2026-07-30. Dynamic text
is deliberately not baked into the art: wallet wager, possible gain, odds,
maturity depth, resource escrow, typed phrase, and result totals remain live.

ImageGen alpha-matte helper. Do not replace it with the opaque full-screen
review PNG from `visual-approval-previews/`.

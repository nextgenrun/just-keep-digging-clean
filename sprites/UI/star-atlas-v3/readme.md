# Star Codex foundation V3

`star-codex-foundation-v3.png` is the active ImageGen-authored foundation for
the `I`-key Star Codex. It keeps V2's measured 1738 x 905 geometry while moving
the presentation toward a calmer product-UI hierarchy: matte charcoal
surfaces, single graphite borders, restrained cyan cues, and generous empty
space for live text and collected Star art.

The bitmap contains no labels, identity art, lore, or progression values.
`values/starIdentityLibrary.js` remains authoritative for every source-space
anchor, runtime string, hit zone, and discovery state. `star-atlas-v2/` is the
direct visual rollback.

# Heavenblocks Progression UI v1

**Date:** 2026-07-26

Production UI and pickup sprites for the upward-progression loop:

- `ancient-relic-token-v1.png` is the 64 px discovery/pickup token.
- `ancient-relic-icon-v1.png` is the simplified 32 px HUD and recipe icon.
- `aether-turbine-v1.png`, `halo-regulator-v1.png`, and
  `eclipse-crucible-v1.png` are the three 64 px protected component icons.

The alpha assets are deterministic reductions of the retained chroma-key
sources. They never own inventory, access, crafting, or save state.

The selected ImageGen outputs were copied without repainting:

  `call_AyDMkuff0SSWYwA1CHtMx6qE.png`

The alpha masters replace only the flat green source matte. Runtime assets are
then split, tightly alpha-cropped, normalized onto one size per family, and
validated by `tools/build_star_discovery_assets.py`.

## Plate prompt

Create a production-quality 1536x1024 sprite sheet containing exactly six
separate premium celestial discovery popup frame plates for a polished fantasy
mining game UI. Use a strict 2-column by 3-row grid with equal cells and the
same centered wide horizontal geometry in every cell. Each frame is a
symmetrical winged crystalline star-light ornament with refined metal and
cosmic-enamel edges, a spacious clean midnight center for runtime text, and an
integrated long empty XP track near the lower third. No words, letters,
numbers, glyphs, labels, buttons, characters, or logos. Reading left-to-right,
top-to-bottom, use Common cyan and ice blue, Uncommon lavender and pink, Rare
gold and amber, Epic ember orange and crimson, Mythic turquoise and teal, and
Astral violet and magenta. Escalate richness, particles, and radiance with
rarity while preserving the shared silhouette. Crisp high-end 2D game UI asset,
readable when reduced, generous isolation around every component. Use a
perfectly flat solid #00FF00 chroma background with no grid, texture, shadows,
or glow leaking into the green.

## XP-fill prompt

Create a production-quality 1536x1024 sprite sheet containing exactly six
separate luminous horizontal Sign XP fill strips for a polished fantasy mining
game UI. Use a strict 2-column by 3-row grid with equal cells and identical
long, slim, centered geometry in every cell. These are fill-only assets: no
outer frame, no backing plate, no text, no numbers, no icons, no labels, and no
logos. Give each strip clean rounded energy ends, a bright traveling core,
fine crystalline/celestial detail, and enough width for smooth runtime crop
animation. Reading left-to-right, top-to-bottom, use Common cyan and ice blue,
Uncommon lavender and pink, Rare gold and amber, Epic ember orange and
crimson, Mythic turquoise and teal, and Astral violet and magenta. Escalate
richness and radiance by rarity while keeping the same silhouette and
dimensions. Crisp high-end 2D game UI asset, readable at 10-25 px high,
generous isolation around each component. Use a perfectly flat solid #00FF00
chroma background with no grid, texture, shadows, or glow leaking into the
green.

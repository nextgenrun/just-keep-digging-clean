# Time-neutral town previews

Preview-only lighting and sky candidates for `town-ground-01.png` through `town-ground-05.png`.

- These files are not referenced by the live TMX, chunks, asset registry, or Phaser runtime.
- Building, roof, door, ground-line geometry, and human scale remain locked to each source panel.
- The sky and global atmosphere use the neutral blue-gray daylight base established by the approved level-one exterior anchor.
- Celestial bodies, stars, lightning, precipitation, and baked weather highlights are excluded so runtime time/weather lighting can be added later.
- The comparison sheet aligns town and exterior panels to one common ground baseline for direct sky-scale review.

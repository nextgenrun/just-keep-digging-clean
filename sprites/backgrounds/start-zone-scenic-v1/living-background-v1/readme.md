# Living surface background V1

Three silent, background-only H.264 loops promoted from the approved Seedance
Mini review. Each runtime file is 1800 x 534, 24 fps, and 432 frames. The media
contains only sky, forest, air, and the Town Square beauty plate; it contains no
slate floor, earth, underground shelf, collision, or gameplay state.

Runtime selects one loop through `values/worldVisualSurfacePacks.js`. The
original static 1801 x 534 beauty crop remains behind it as the fail-safe image.
`?surfaceMotion=0` disables video, while `soft-canopy`, `town-air`, and
`layered-night` select the three production-ready variants.

`surface-living-background-v1.manifest.json` records source/output hashes,
dimensions, cadence, duration, and the ground/audio boundary.

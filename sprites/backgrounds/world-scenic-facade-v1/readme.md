# World scenic facade materials v1

These eight mirrored-seamless WebP materials are deterministic derivatives of
the approved v11 high-resolution depth-detail sources. Runtime projects them in
world space only through authoritative solid cells. Digging removes the mask,
damage uses integrated cracks, and resources remain separate recognition art.

Rebuild with `python ai-tools/2026-07-15-build-world-scenic-facade-materials.py`.

# Layered ground damage V3 sources

`2026-08-26-ground-damage-fracture-library-chroma-v3.png` is the retained
1254x1254 result of the built-in image-generation workflow. The first pass
requested a 4x4 grid of materially neutral, orthographic fracture silhouettes
with distinct radial, diagonal, split, crushed, branching, and shear shapes.
The cleanup edit replaced the baked transparency checker with chroma green
while preserving all sixteen cells. The dated builder removes that chroma and
performs every crop, cumulative-state build, atlas assembly, and validation.

Do not load this source in the game. Runtime loads only the alpha atlases in
the parent semantic-decals directory.

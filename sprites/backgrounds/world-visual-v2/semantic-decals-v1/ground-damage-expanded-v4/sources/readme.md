# Expanded ground damage V4 sources

- `2026-08-26-ground-damage-compression-chroma-v4.png` contains sixteen
  approved compression/impact motifs on a chroma source background.
- `2026-08-26-ground-damage-shear-alpha-v4.png` contains sixteen transparent
  directional shear/split motifs.
- `2026-08-26-ground-damage-brittle-alpha-v4.png` contains sixteen transparent
  brittle, plate, lattice, and delamination motifs.

All three are OpenAI built-in image-generation outputs. The builder alpha-cleans
the chroma sheet, normalizes each irregular source grid to exact 4x4 cells, and
combines them with the retained V3 alpha sheet. Source sheets are never loaded
by Phaser directly.

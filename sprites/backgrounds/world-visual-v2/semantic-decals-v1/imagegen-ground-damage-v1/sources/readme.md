# Ground damage ImageGen sources

Accepted 1536 x 1024 built-in ImageGen chroma sheets.

Each file contains one authored fracture family arranged as exactly four
columns by three rows. Cells read left-to-right, then top-to-bottom, and
represent cumulative proportional-damage states 1 through 12.

Keep these sources unchanged for provenance. Re-run the installed ImageGen
chroma-removal helper to update the corresponding file in `../alpha-sheets/`.

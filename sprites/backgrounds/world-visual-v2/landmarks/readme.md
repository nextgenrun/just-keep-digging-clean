# World Visual V2 Landmarks

This folder contains versioned, transparent scenic landmark cutouts used by the World Visual V2 runtime.

## Assets

- `underground-cave-mouth-v1.png` — compact front-facing underground CaveScene entrance with a neutral graphite, timber, amber, and cold-blue palette. The PNG is RGBA and has no baked ground slab, UI, or collision authority.

These images are presentation assets only. Gameplay placement, collision, interaction, and scene-entry logic remain authoritative in code and configuration.

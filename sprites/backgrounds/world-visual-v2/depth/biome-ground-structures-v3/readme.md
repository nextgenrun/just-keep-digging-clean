# Biome Ground Structures V3

Fifty additive 1536x1024 transparent ImageGen-authored terrain-structure plates:
five for each production depth biome.

- Runtime plates are masked to authoritative solid terrain.
- They render above continuous material but below resources, rewards, damage,
  physical effects, and emissive feedback.
- They do not change tile type, HP, collision, drops, saves, or cave topology.
- Every image is chroma-keyed with green-spill decontamination from a preserved
  lossless source.
- `?undergroundGroundStructures=0` disables the complete layer.

Lossless chroma and alpha sources, prompt provenance, hashes, coverage metrics,
and review sheets live under
`visual-approval-previews/underground-visual-expansion-v3/`.

The approved compositions are also preserved as alpha-feathered V4 runtime
derivatives in `../biome-ground-structures-v4/`. Use
`?groundStructureBlend=0` to compare against these original V3 runtime files.

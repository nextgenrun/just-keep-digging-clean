# Biome Ground Structures V4

Fifty alpha-feathered runtime derivatives of the approved V3 ground-structure
plates. The source compositions are unchanged; V4 removes hard card edges and
mirrored joins by overlapping native 1536x1024 cards at a 1344x896 stride.

- V3 runtime and lossless source files remain intact.
- Authoritative solid-terrain geometry is still the only gameplay mask.
- The structures remain below resources, rewards, damage, physical effects,
  and emissive feedback.
- Collision, tile HP, drops, saves, and cave topology are unchanged.
- `?groundStructureBlend=0` restores the V3 asset set for comparison.
- `?undergroundGroundStructures=0` disables the whole optional layer.

The V4 derivative manifest and review sheet live under
`visual-approval-previews/underground-terrain-blend-v4/`.

# Level One Biome Generated Roles V3

This folder contains 120 terrain-masked, demand-streamed WebPs for the 30 biome
families added by the 50-family expansion. Each added family owns one background,
signature, ground, and foreground asset. They are visual-only and use
`?levelOneSourceFamilies=0` for rollback.

Here `ground` means a transparent terrain-clinging landmark. Actual continuous
ground fill for the added families lives in `level1-biome-ground-materials-v1/`.

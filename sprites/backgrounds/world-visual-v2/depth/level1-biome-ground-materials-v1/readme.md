# Level One family ground materials V1

Sixty 1536x1024 RGBA WebP terrain plates are generated from the reviewed
ImageGen sources. The terrain-variation renderer masks them to authoritative
solid tiles and demand-streams only plates required by the visible organic
biome territories. They never modify tile type, HP, collision, resources,
drops, map topology, or saves.

These sixty plates supplement thirty-six retained terrain concepts for a total
of ninety-six. They are continuous ground fill; the similarly named V3
`ground` role is only a transparent terrain-edge landmark.

Rollback: `?levelOneSourceFamilies=0`.

# Level 1 Biome Boundaries V1

Seven transparent ImageGen foreground cutouts make every resolved material-family
join in the shared Level 1 X0-131, 0-2000 m biome field legible:

- `weathered-roots-to-cobalt-v1.webp`
- `cobalt-to-amber-v1.webp`
- `weathered-roots-to-amber-v1.webp`
- `amber-to-silver-v1.webp`
- `cobalt-to-silver-v1.webp`
- `silver-to-magma-v1.webp`
- `amber-to-magma-v1.webp`

The built-in ImageGen workflow used the matching production V6 prop atlases as
style references. The deeper regions still reuse the much larger authored
handoff/enhancer/detail library. Four cutouts close the measured Amber/Silver,
Cobalt/Silver, Silver/Magma, and occasional Amber/Magma overlay gaps. The 2026-08-28
candidates required a background-only chroma correction after validation found
a baked checkerboard; the Cobalt/Silver source arrived with native alpha. Every
promoted WebP has real alpha and a narrow outer safety feather. Runtime
placement remains deterministic, below resources/damage, and
clipped by the authoritative scenic terrain mask. These images never create
collision, terrain, rewards, or save state.

The final prompt family requested one connected, grounded, strict side-view
formation with interwoven source materials, a genuinely transparent backdrop,
no panel, text, characters, UI, particles, or cropped edges.

The deep assets were promoted reproducibly by
`ai-tools/2026-08-28-build-level-one-deep-biome-boundaries-v1.py`; unmodified
ImageGen results and any background-only chroma edits remain in `sources/`.

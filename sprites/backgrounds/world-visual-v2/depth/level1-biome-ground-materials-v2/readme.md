# Level One Family Ground Materials V2

Fifty tertiary 1536x1024 terrain plates add one true ground-material choice to
every named Level One family. The terrain-variation renderer selects them
inside its existing world-space plate slots and masks them to authoritative
solid tiles. The assets never modify terrain, HP, collision, resources, drops,
map topology, or saves.

Rollback: `?levelOneSourceFamilies=0`.

# Level One Biome Signatures V1

Twenty `1536x1024` RGBA WebP foreground formations, one for every Level One
visual biome source family. Each is placed at the irregular field seed that
owns its territory, demand-streamed near the camera, and clipped through the
authoritative solid-terrain mask.

The layer is decorative and non-colliding. It never changes terrain type, HP,
digging, resources, drops, cave topology, map ownership, or saves. Use
`?levelOneSourceFamilies=0` to restore the former five shared visual pools and
remove these signature formations.

# Biome Expansion V3

Fifty additive 1536x1024 ImageGen-authored underground background cards: five
new compositions for each of the ten production depth biomes.

- Cards render only at far-backdrop depth.
- Buildings, bridges, roots, rails, machinery, ruins, and monumental landmarks
  remain distant scenery and never become collision ground.
- Existing V2 static cards, named concept statics, and smooth V3 video cards
  remain unchanged.
- Runtime selection is deterministic and streamed.
- `?biomeBackdropExpansion=0` disables only these fifty additions.

Lossless sources, prompt provenance, hashes, and review sheets live under
`visual-approval-previews/underground-visual-expansion-v3/`.

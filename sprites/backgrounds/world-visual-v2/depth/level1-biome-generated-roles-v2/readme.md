# Level One Biome Generated Roles V2

Demand-streamed WebP derivatives for the Level One visual biome field. Every
one of the twenty source families owns a background, ground, and foreground
asset here; the retained hero signature lives in the adjacent V1 signature
directory.

The renderer applies deterministic role-specific position, scale, flip,
rotation, alpha, and depth while clipping all images to the terrain mask. No
file in this directory has collision, resource, gameplay, or save authority.

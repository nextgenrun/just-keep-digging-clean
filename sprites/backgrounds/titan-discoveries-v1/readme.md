# Titan Discoveries v1

Visual-only titan silhouettes used in two places:

- enormous distant cave-backdrop discoveries revealed through dug terrain;
- small non-interactive surface echoes that accumulate as titans are found.

The 25 runtime PNGs are derived from the dated chroma-key atlas in `sources/`
by `ai-tools/2026-07-26-build-titan-sprites.py`. They never define collision,
rewards, stats, or tile state.

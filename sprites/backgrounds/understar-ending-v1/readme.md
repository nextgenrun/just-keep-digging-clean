# Understar Ending V1

Production finale art for the demo's 2,000 m ending.

- Runtime: `understar-ending-backdrop-v1.webp`
- Dimensions: 1672x941
- Source mode: OpenAI ImageGen built-in generation, then WebP quality 92
- Role: one shared authored painting for the in-world discovery and the
  full-screen completion overlay

The prompt specifies an impossibly enormous white-gold and cyan stellar body
embedded in a blackglass cavern, cropped beyond the image boundaries with tiny
ruins and broken celestial rings for scale. It explicitly excludes text, UI,
characters, collectible-star shapes, generic space scenery, and procedural
substitute art.

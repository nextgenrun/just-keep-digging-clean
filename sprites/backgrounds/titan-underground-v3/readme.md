Production bitmap grounding and unlock accents shared by all 25 underground Titans.

- `titan-ground-contact-v1.png` is a 1198x292 RGBA fractured-earth and mineral foreground. Runtime scales it below native density, places it over the feet, and mixes it toward the active depth-biome tint.
- `titan-unlock-resonance-v1.png` is a 1511x1041 RGBA fractured mineral resonance field. It appears behind the Titan only during the short unlock beat.
- `sources/` retains the dated ImageGen chroma sources and its own provenance note.

These two assets supplement the existing Titan stance, chamber, and biome V7 backdrop libraries. No collision, reward, save, or discovery threshold is encoded in the artwork.

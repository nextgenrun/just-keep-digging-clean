# V11 Runtime Polished Backgrounds V4

Production background package for the saved v11 world.

- `surface/` contains the approved neutral-sky surface chunks used at runtime.
- `depth-chunks/` contains deterministic streamed Level 1 and Level 2 chunks through the prepared 2,000m art envelope.
- `sources/` preserves the approved overview concepts and detail plates used by the reproducible builder.
- Level 2 future 2,000–5,000m source art is retained in `sources/`, but remains dormant until the runtime world is extended.
- Runtime rollback: `?worldMaster=0` disables the full package; `?worldDepthMaster=0` disables only the new underground chunks.

Build with `ai-tools/2026-07-12-build-v11-runtime-backgrounds-v4.py`.

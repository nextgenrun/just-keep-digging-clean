# Opening Flight V2

Versioned Golden Five artwork for the first-run flight encounter.

- `sources/` preserves the built-in ImageGen chroma-key outputs.
- `runtime/*-alpha-v1.png` preserves the locally keyed transparent masters.
- `runtime/*-v2.webp` contains cropped, alpha-safe, lossless production sprites.
- `ai-tools/2026-07-26-build-opening-flight-v2-assets.py` rebuilds the compact
  runtime WebPs from the transparent masters.

The five runtime roles are the buried Flight Artifact, diegetic shaft marker,
forgiving ascent ring, one-time First Ascent Cache, and premium dynamic-text
objective HUD frame.

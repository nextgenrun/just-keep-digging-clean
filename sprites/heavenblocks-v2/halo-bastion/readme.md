# Halo Bastion runtime sprites

These transparent WebPs are modular runtime parts for the Level 1 Halo Bastion.
Terrain roles are selected per authoritative `WorldModel` cell; props, portal,
shrine, relic vault, component, and barrier art are separate display objects.
No file in this directory is a complete island painting.

Paths and texture keys are owned by `values/heavenblocksVisualConfig.js`.

# Cinder Lance artwork

Exact prompts: `testing/2026-09-05-lance-three-versions/2026-09-05-cinder-variant-prompts.md`. Motion/rarity: `values/stellarLancePresentation.js`. The image stays fixed in size during flight, with a single steady opacity fade to 32%.

# Approved World Tiles

Production-approved raster tiles used by the legacy and scenic world renderers.

- `bedrock-megalith-lock-v1.png` is the approved Level 1/Level 2 separator
  material. Its source is the user-selected 1254 x 1254 Megalith Lock image,
  preserved byte-for-byte. The scenic semantic package contains an identical
  copy for its package-local asset contract.
- `bedrock-wall.webp` remains as the previous rollback asset and is not the
  default bedrock route.

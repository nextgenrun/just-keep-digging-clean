# Branding

Runtime and legacy game-brand assets.

- `understar-logo-v1/` contains the approved UNDERSTAR floating-logo runtime
  asset.
- `logo-enter-v-1/` retains the legacy Just Keep Digging source for rollback
  evidence only. It is no longer loaded by the game.

The authoritative live name and logo path are defined in
`values/branding.js`.

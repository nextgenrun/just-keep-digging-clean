# Surface and Sky Props V3 Sources

Built-in ImageGen produced ten exact 5-by-4 extraction sheets using the
approved V2 prop scale sheet and the matching surface/sky chapter art strictly
as style references.

Green or magenta chroma backgrounds are removed with the installed ImageGen
`remove_chroma_key.py` helper. The resulting alpha-master PNGs remain
provenance only; the dated builder validates twenty isolated cells per sheet,
trims frames, writes atlas metadata, hashes outputs, and builds review sheets.

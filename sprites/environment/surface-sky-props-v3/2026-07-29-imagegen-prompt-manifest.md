# Surface and Sky Props V3 ImageGen Prompt Manifest

## Generation mode and references

Mode: OpenAI built-in image generation.

Primary style references:

- `visual-approval-previews/surface-props-v2-additive-runtime/2026-07-28-existing-plus-additive-prop-scale-sheet-v2.png`
- `visual-approval-previews/surface-landscape-final-library-v1/2026-07-28-overview-all-14-surface-segments-v1.png`

Each output was requested as exactly twenty isolated objects in a strict 5-by-4
grid. The references controlled rendering language only; no reference object
was copied as a duplicate runtime prop.

## Shared production prompt

Create exactly 20 separate production-ready 2D environmental game-prop
cutouts, arranged left-to-right in a strict 5-column by 4-row grid. Match the
reference world's premium painterly-realistic, exact side-on orthographic
visual language: cobalt moonlit mountain-forest atmosphere, restrained local
amber light, weathered timber, dark iron, brass, rope, canvas, stone, and
believable material wear. Keep every object fully isolated with generous
gutter space and a planted baseline. Use a solid chroma background suitable
for clean alpha extraction. No characters, creatures, terrain strip, sky,
moon, UI, labels, readable text, numbers, logos, duplicated objects, borders,
or drop shadows crossing into another grid cell.

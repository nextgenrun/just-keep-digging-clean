# Random event world sprites V1

`random-event-sigils-v1.png` is a shared transparent authored atlas. Active
runtime crops serve Crystal Choir, Blackout Bloom, and Money Monster Rush.
The source was generated from the player-approved event direction and processed
with the bundled ImageGen chroma-key helper.

Runtime crop rectangles and display sizes are authoritative in
`values/randomWorldEvents.js`. These sprites are presentation-only and never
mutate the tile grid.

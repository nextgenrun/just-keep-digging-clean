# Root Sanctuary V1

ImageGen-authored trunk plus five independent living/killed foliage pairs.
Stars, Crown, Talent access and all ten Campfires are separate runtime objects.
Nothing in this art supplies collision. The real town ground owns the player's feet.

`source/` preserves the original generated plates. The date-stamped builder
removes their magenta carrier and extracts atlas cells without repainting art.
`manifest.json` records dimensions, alpha, cells, source and runtime hashes.
Configuration and placement live in `values/worldrootSanctuary.js`.

`?worldrootArt=v4` and `?worldrootArt=v3` retain previous visual rollbacks.
The whitebox review remains explicit and independent.

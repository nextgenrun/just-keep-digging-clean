# Hardcore Memorial V1

Approved ImageGen-authored permanent world grave for erased Hardcore runs.

- `hardcore-memorial-master-v1.png` is the transparent high-resolution master.
- `hardcore-memorial-runtime-v1.webp` is the bounded lossless runtime asset.

The memorial is decorative and non-colliding. Runtime placement, interaction,
and bounded cross-run persistence are configured by
`values/hardcoreMemorials.js`.

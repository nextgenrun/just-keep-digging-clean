## Shared production prompt

Create exactly 25 independent premium light-only assets in an invisible 5 by 5
row-major grid on pure `#000000`. Each cell contains a centered, broad,
soft-feathered illumination stain plus its named phenomenon and exact primary
hue. Every effect fades fully to black before the cell edge. Use high-end
hand-painted cosmic fantasy game VFX suitable for additive composition.

Do not draw text, labels, numbers, borders, grid lines, UI, terrain,
characters, literal creatures, physical stars, five-point silhouettes,
crystals, gemstones, watermarks, logos, checkerboards, or cropped glows.

Each call supplied the exact 25 identity names, primary hex colours, and light
styles for its page. Page 09 received one targeted built-in edit to remove
literal dragon-head readings while preserving the grid, colors, and abstract
light effects; the edited call above is the production source.

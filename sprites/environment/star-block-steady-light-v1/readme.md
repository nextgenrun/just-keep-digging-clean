# Star Block Steady Light V1

Six 1254 × 1254 ImageGen-authored additive light textures in production rarity
order:

1. cyan
2. lavender
3. gold
4. orange
5. turquoise
6. violet

Each source is centered on pure black and fades fully to black before the image
edge. `SkySteadyLightRenderer` may position, scale, alpha-fade, and additively
composite these images. It must not tint one generic asset, draw replacement
Phaser geometry, add a ring or cross, or substitute the player torch glow.

The cyan source established the shared silhouette: a softly flattened,
long-feathered light stain with restrained cosmic dust near the center. The
remaining five sources preserve that composition while changing only the
authored rarity color.

# Root Sanctuary V3

Tall, naturally coloured modular tree artwork produced with built-in ImageGen.
The original generated images and prompts are preserved in `source/` and
`generation.json`. `manifest.json` records native dimensions, alpha and hashes.

One trunk and a shared living/dead branch pair serve five independent runtime
regions. Each region keeps its own discovery, growth and consumption state.
Stars, Campfire, ground controls and collision are never baked into this art.

`ai-tools/2026-09-03-build-worldroot-sanctuary-v3.mjs` removes the neutral carrier
and edge contamination with the user's explicit permission. Background colour
is unmixed only at silhouette fringes; native size and interior foreground are
unchanged. Old art remains untouched in V1/V2.

# Old-school lamp ImageGen masters

Exact 1254x1254 outputs from the built-in ImageGen workflow. These files are
immutable inputs for the dated lamp-light builder and are never loaded by
Phaser.

`prompts.json` records the seven production prompt specifications. The builder
crops one edge pixel to obtain a 1252x1252 sheet with sixteen equal 313x313
cells, then performs integer-only anchor registration through editable Piskel
projects.

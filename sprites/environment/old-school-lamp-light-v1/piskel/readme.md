# Old-school lamp Piskel package

- `registered-source/` contains the immutable normalized ImageGen imports.
- `polished-work/` contains seven editable fixed-anchor `.piskel` authorities.
- `rollback-v1/` contains exact source-project recovery copies.
- `runtime-original-v1/` contains the normalized pre-registration atlases.
- `strips/` contains 16x1 frame-order review exports.

Every project has sixteen 313x313 frames, a hidden anchor/safe-border guide
layer, integer-only registration, and pixel-identical Piskel round-trip.

Regenerate the review assets with:

```powershell
python -B ai-tools/2026-07-30-build-old-school-lamp-light-v1.py
```

The family is review-only and query-gated; the builder never replaces Fire
Light V3.

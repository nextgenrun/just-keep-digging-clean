## Shared prompt contract

- Premium faceted five-point crystal Star with a crisp readable core.
- One isolated identity per equal cell, centered and consistently scaled.
- Exact listed primary hue dominates the crystal and its local glow.
- Pure `#000000` background; the build converts luminosity to alpha.
- No text, labels, numbers, frames, grid lines, UI, terrain, characters,
  watermark, or border.
- No particles or glow crossing cell boundaries.
- Rarity escalates from restrained Common halos to impossible Astral
  singularities without changing the shared crystal family.

The original V1 sheets are not duplicated here. The V2 builder reads those
immutable sources directly for frames 0-49.

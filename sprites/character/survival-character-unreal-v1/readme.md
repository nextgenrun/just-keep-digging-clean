# Survival Character Unreal V1

Runtime animation sheets for the approved Fab Survival Character. Motion comes
from native Unreal Engine 5.8 Manny template AnimSequences retargeted through
Unreal's IK Rig / IK Retargeter; Blender is used only for textured presentation
rendering and sheet assembly.

Clips:

- idle
- walk
- run
- fly (UE5 airborne/fall loop, presented with the character's backpack)
- attack
- dig-side (charged attack base with a mining pickaxe)
- dig-up (second UE5 attack motion with a mining pickaxe)
- dig-down (third UE5 attack motion with a mining pickaxe)

The source Unreal reports live in
`testing/unreal-survival-motion-v2/SourceAssets`. Runtime sheets and the manifest
are generated by `ai-tools/2026-07-15-build-survival-unreal-motion-v1.py`.

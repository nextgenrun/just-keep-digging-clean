# Arc Core Review V2

Review-only, drift-locked sprite package for the Small and Omega Arc Core
animation mockups in `testing/animation-sandbox/tanktest-v1`.

The package uses one fixed master body per Arc form. Motion comes from separate
energy-ring, lattice-sigil, cloud, and in-engine beam layers, so animation never
crossfades independently generated whole-body frames.

- `source/` retains the selected ImageGen chroma masters and approved alpha
  extractions.
- `runtime/` contains normalized 512 px sprites generated by
  `tools/build_arc_core_sprite_package.py`.
- Its former manifest was superseded by the approved
  `values/arcCoreVisuals.sprite.json` v3 production pack.

This package is historical review evidence and is not game-loaded.

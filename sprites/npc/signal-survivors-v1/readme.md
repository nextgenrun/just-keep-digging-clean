# Signal survivor sheets and minicamp

Built-in ImageGen authored transparent masters matching the existing player-upgrades NPC. Ivo, Bram and Oren each have four poses in a 2 by 2 sheet: resting, calling, gratitude and guarded. Mia is a female shepherd with a worn leash and a MIA name plate; her four poses use the same engine rendering and cinematic framing. The minicamp has bedding, supplies and a lamp around an open standing area.

Phaser builds the cinematic and the cleared world minicamp from these assets. Source images remain intact in the generation folder. RGBA transparency is verified; portrait crop metadata does not resample the source artwork.

# Worldroot hearth evolution

Ten independently generated Campfire forms share the living tree's bark, stone
and fire palette. The original sprites in `../generated/` remain untouched.

`sources/` retains the exact native built-in ImageGen outputs with their
painted backgrounds. `runtime/` contains deterministic full-resolution RGBA
cutouts and a hash/alpha manifest. Normal play selects the runtime directory;
the source directory remains provenance-only and is excluded from production.

Generation prompts and provenance are recorded alongside this file.

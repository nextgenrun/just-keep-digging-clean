# Campfire forms

`campfire-tier-01.png` through `campfire-tier-10.png` are the original
metal-brazier rollback sprites. Their art is unchanged by the Root Sanctuary
implementation, but normal runtime loading no longer selects this directory.
All use the existing common ground anchor, original aspect ratios and values-owned
display heights. The explicit 42–171 px growth ramp now makes tier 10 both
widest and tallest; each tier is at least 12 px taller than the previous form
at the current 94 px tile size. Purchases animate the two real tier textures.

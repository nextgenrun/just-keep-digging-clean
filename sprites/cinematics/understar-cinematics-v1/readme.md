# UNDERSTAR Cinematics V1

Runtime-ready H.264/AAC cinematics for the game.

- `understar-opening-v1.mp4` plays at game startup before the main menu and
  remains skippable.
- `mossback-discovery-v1.mp4` plays only when the first Titan,
  `mossback-wanderer`, is newly discovered and remains skippable.
- matching poster images cover loading and the browser gesture gate; decode or
  playback failure exits safely without blocking the menu or game.

These videos are presentation-only. They do not mutate progression, discovery,
terrain, rewards, or save authority.
